# 🥗 Abhisekh ka vatsavik tracker

A free, open-source calorie and macro tracker. One HTML file, no build step, no accounts, no server.

## Features
- Daily calorie and macro (protein, carbs, fats) logging
- Water tracker, weight log with chart, 14-day progress and streak
- Built-in database of common Indian foods, plus your own saved foods
- Goal calculator (Mifflin-St Jeor)
- Light/dark theme, works on phone and desktop
- Data stays in your browser (localStorage); backup/restore from Settings

## Run it
Open `index.html` in any browser. That's it.

## Host it free
- **GitHub Pages:** push this folder to a repo, then Settings → Pages → deploy from `main` branch.
- **Netlify / Cloudflare Pages / Vercel:** drag and drop the folder.

## Contribute
Pull requests welcome. Ideas: more foods, barcode scan, PWA/offline install, more languages.
Food values are approximate and for general guidance only, not medical advice.
